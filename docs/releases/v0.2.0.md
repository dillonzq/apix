# v0.2.0

English | [简体中文](v0.2.0.zh-CN.md)

apix v0.2.0 improves request inspection, JSON field editing, inline-media Base64 handling, and Responses stream processing. The public Go API and supported protocol directions are unchanged. Go **1.26.10+** is still required.

## Compatibility

- **One external dependency:** production and test code now depend on `github.com/MoeForge/moego v0.1.0-alpha.1`, whose own dependencies are limited to the standard library. Its `base64` package handles media validation and encoding; `ojson` powers order-preserving JSON reads and edits. The dependency check continues to reject every other external module.
- **JSON byte output changes:** edited requests and selected SSE payloads now preserve untouched member order, whitespace, and number spelling instead of re-encoding the whole object with sorted keys. New members are appended. JSON meaning is preserved, but callers comparing exact bytes should review their fixtures. This wire-output change is released as a minor version under the project's pre-1.0 versioning policy.
- Fast paths decline ambiguous keys, non-object parents, and invalid JSON; callers fall back to the existing `encoding/json` paths. Fallback output may still be re-encoded and sorted, so member order is not an unconditional guarantee.
- moego's default allocator uses `//go:linkname runtime.mallocgc`. Build with `-tags moego_zeroalloc` or `-tags purego` to use ordinary allocation. See [design rules](../../CONTRIBUTING.md#design-rules).

## Changes

- **Request edits:** native model rewrites, reasoning overrides and removal of superseded controls, Responses tool normalization, and native image model/stream rewrites use `internal/jsonedit` where applicable. Unrelated fields retain their bytes on these fast paths.
- **Routing inspection:** shared LLM routing fields and feature scans use ojson, and request conversion avoids the feature scan when it needs only routing values and protocol validation. Duplicate-key and string decoding behavior retains compatibility with `encoding/json` through guarded reads and fallback.
- **Media:** Base64 validation and encoding use moego for inline LLM media and image payloads. Text-document conversion still decodes and validates UTF-8 where required.
- **Streams:** synthesized Responses sequence numbers and native function-call event identity restoration edit only the relevant fields where possible. Untouched native frames and native sequence numbers are preserved.
- **SSE framing fix:** edited multi-line JSON is compacted before it is wrapped in a `data:` field, preventing embedded line breaks from truncating the event payload.
- **Validation tools:** request, inspection, stream, and media benchmarks plus JSON-edit and differential fuzz tests cover the optimized paths, ambiguous keys, exact numeric values, and standard-library parity.

## Upgrade

```sh
go get github.com/dillonzq/apix@v0.2.0
```

No public API migration is needed. Update dependency allowlists and any fixtures that assert exact JSON bytes. See [architecture](../architecture.md#json-reads-and-edits) for fast-path and fallback details.
