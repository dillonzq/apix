# v0.4.0

English | [简体中文](v0.4.0.zh-CN.md)

apix v0.4.0 renames the Gemini vendor namespace to `google`, adds token counting that converts across Anthropic, OpenAI, and Google, and hardens the gateway's redirects, stream health reporting, and SSE frame sizes. This release contains breaking renames; Go **1.26.10+** is still required.

## Breaking changes

- **`protocol/gemini` becomes `protocol/google`.** Vendor packages and protocol ID prefixes now name the company, like `openai` and `anthropic`; the package also holds Imagen, which is not Gemini. Constant and function names inside the package are unchanged.
- **Protocol IDs change prefix:** `gemini.generate-content`, `gemini.interactions`, `gemini.generate-content.image`, and `gemini.imagen` become `google.*`. Update any stored or configured IDs, such as endpoint protocols in routing configuration.
- **`reasoning.Options.GeminiMode` becomes `GoogleMode`.**
- **Generated tool call IDs:** a GenerateContent function call without an `id` that converts to another protocol now gets `call_google_N` instead of `call_gemini_N`. IDs from earlier turns are still accepted as opaque strings; only clients that parse the prefix need updating.
- **Text naming the vendor:** error messages and the refusal text for a blocked prompt (`Request blocked by Google.`) say Google where they said Gemini. Model names are unchanged.
- **SSE frames are limited to 64 MiB by default.** An upstream frame larger than the limit now fails the stream with `sse.ErrFrameTooLarge`; frames before it are still delivered. The limit applies to one frame, not the whole stream. Raise it for large image frames, or set a negative value to disable it for trusted upstreams (see below).
- **The default gateway client no longer follows cross-origin redirects.** Redirects must keep the original scheme, hostname, and effective port, so credentials never reach another host. A caller-supplied `Config.Client` keeps its own redirect policy.

The 48 conversion snapshots are byte-identical; the 21 GenerateContent snapshots are renamed only.

## Changes

- **Token counting:** the new `apix.KindTokens` kind counts the input tokens of an LLM request without generating. `anthropic.MessagesCountTokens` (`/v1/messages/count_tokens`), `openai.ResponsesInputTokens` (`/v1/responses/input_tokens`), and `google.CountTokens` (`:countTokens`) convert directly in all six directions, and each vendor's `Codecs()` includes them. Count bodies convert through the LLM engine and are reshaped for the upstream endpoint: generation controls are dropped, and Google receives the `generateContentRequest` form so system instructions and tools are counted. Native requests keep their bytes apart from the model. Counts do not stream. See [token counting](../protocols/tokens.md).
- **SSE frame limits:** `sse.FrameLimiter`, `sse.NewFramerWithLimit`, `sse.DefaultMaxFrameBytes`, and `Framer.Err` bound frames across arbitrary chunks without buffering them. Every built-in codec, the gateway, and usage tracking enforce the limit. Configure it with `gateway.Config.MaxStreamFrameBytes`, per endpoint with `route.EndpointOptions.MaxStreamFrameBytes`, or per exchange with `apix.ExchangeOptions.MaxStreamFrameBytes`. See [stream frame limits](../gateway.md#stream-frame-limits).
- **Stream health:** committed streams report health exactly once when they end, so consecutive network failures can trip the circuit breaker, and only complete responses clear earlier failures. Cancellation keeps its cause without penalizing the endpoint, including a close racing a read and a cancellation followed by upstream EOF. Inconclusive half-open probes are released.
- **Routing edge cases:** weight sums that overflow `int` use exact arbitrary-precision draws, and extreme priorities are compared without subtraction overflow.
- **Validation tools:** new fuzz targets cover token counting and frame limits at chunk boundaries, and CI archives the fuzz failure corpus of every package.

## Upgrade

```sh
go get github.com/dillonzq/apix@v0.4.0
```

Replace the import path `github.com/dillonzq/apix/protocol/gemini` with `github.com/dillonzq/apix/protocol/google` and the package qualifier `gemini.` with `google.`, rename `reasoning.Options.GeminiMode` to `GoogleMode`, and replace `gemini.` protocol ID strings in configuration with `google.`. If your upstreams send SSE frames larger than 64 MiB, set `MaxStreamFrameBytes`. If you relied on the default gateway client following redirects to another origin, supply your own `Config.Client`.
