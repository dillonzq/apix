# v0.4.0

[English](v0.4.0.md) | 简体中文

apix v0.4.0 将 Gemini 供应商命名空间更名为 `google`，新增可在 Anthropic、OpenAI 与 Google 之间互相转换的 Token 计数，并加固网关的重定向、流健康上报与 SSE 帧大小限制。本版本包含破坏性重命名；仍要求 Go **1.26.10+**。

## 破坏性变更

- **`protocol/gemini` 更名为 `protocol/google`。**供应商包与协议 ID 前缀现在统一使用公司名，与 `openai`、`anthropic` 一致；该包同时包含并不属于 Gemini 的 Imagen。包内常量与函数名不变。
- **协议 ID 前缀变更：**`gemini.generate-content`、`gemini.interactions`、`gemini.generate-content.image` 与 `gemini.imagen` 改为 `google.*`。请同步更新已存储或已配置的 ID，例如路由配置中的端点协议。
- **`reasoning.Options.GeminiMode` 更名为 `GoogleMode`。**
- **生成的工具调用 ID：**没有 `id` 的 GenerateContent 函数调用转换到其他协议时，生成的 ID 由 `call_gemini_N` 改为 `call_google_N`。之前轮次的 ID 仍作为不透明字符串接受；只有解析该前缀的客户端需要调整。
- **指代供应商的文本：**错误信息以及提示被拦截时的拒绝文本（`Request blocked by Google.`）中，原先写作 Gemini 的地方改为 Google。模型名称不变。
- **SSE 帧默认上限为 64 MiB。**上游单帧超过上限时，流以 `sse.ErrFrameTooLarge` 失败；之前的帧仍会交付。上限针对单帧，而非整条流。较大的图像帧应提高上限；对可信上游可设为负值以关闭限制（见下文）。
- **网关默认客户端不再跟随跨源重定向。**重定向必须保持原有的协议、主机名与有效端口，确保凭据不会发往其他主机。调用方自行提供的 `Config.Client` 沿用其自身的重定向策略。

48 份转换快照逐字节一致；其中 21 份 GenerateContent 快照仅改名。

## 变更

- **Token 计数：**新增 `apix.KindTokens`，在不生成内容的情况下统计 LLM 请求的输入 Token。`anthropic.MessagesCountTokens`（`/v1/messages/count_tokens`）、`openai.ResponsesInputTokens`（`/v1/responses/input_tokens`）与 `google.CountTokens`（`:countTokens`）在全部六个方向直接互转，各供应商的 `Codecs()` 均已包含。计数请求体经 LLM 引擎转换后按上游端点重塑：丢弃生成控制参数，发往 Google 时使用 `generateContentRequest` 形式，使系统指令与工具也计入统计。原生请求除模型外保持原始字节。计数不支持流式。详见 [Token 计数](../protocols/tokens.zh-CN.md)。
- **SSE 帧上限：**`sse.FrameLimiter`、`sse.NewFramerWithLimit`、`sse.DefaultMaxFrameBytes` 与 `Framer.Err` 可跨任意分块限制帧大小，且无需缓冲整帧。所有内置 Codec、网关与用量跟踪都会执行该限制。可通过 `gateway.Config.MaxStreamFrameBytes` 配置，按端点用 `route.EndpointOptions.MaxStreamFrameBytes`，按 Exchange 用 `apix.ExchangeOptions.MaxStreamFrameBytes`。详见[流式帧上限](../gateway.zh-CN.md#流式帧上限)。
- **流健康：**已提交的流在结束时只上报一次健康状态，因此连续的网络故障可以触发熔断，且只有完整的响应才会清除之前的失败记录。取消会保留原因且不惩罚端点，包括关闭与读取并发、取消后上游返回 EOF 等情况。结论不明的半开探测会被释放。
- **路由边界情况：**权重之和溢出 `int` 时改用精确的任意精度抽样，极端优先级的比较不再因减法溢出出错。
- **验证工具：**新增覆盖 Token 计数与分块边界处帧上限的 fuzz 目标；CI 会归档每个包的 fuzz 失败语料。

## 升级

```sh
go get github.com/dillonzq/apix@v0.4.0
```

将导入路径 `github.com/dillonzq/apix/protocol/gemini` 替换为 `github.com/dillonzq/apix/protocol/google`，包限定符 `gemini.` 替换为 `google.`；将 `reasoning.Options.GeminiMode` 改为 `GoogleMode`；把配置中以 `gemini.` 开头的协议 ID 字符串改为 `google.`。如果上游会发送超过 64 MiB 的 SSE 帧，请设置 `MaxStreamFrameBytes`。如果依赖网关默认客户端跟随跨源重定向，请自行提供 `Config.Client`。
